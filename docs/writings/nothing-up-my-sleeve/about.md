# About this book

*What a reader is pointed to once the book is read: where it is kept, how it was decided, and where the experiments are reported.*

The book is kept as plain text in Thorp's repository, under `docs/writings/nothing-up-my-sleeve`: one folder for each part, a file for each chapter, and beside each chapter a file of notes that holds its sources and Quentin Luck's footnotes. The plan, which outlines every chapter, and the register of decisions, which says why the book is the way it is, follow this page, and after them the notes taken on each version as it was read on a Kindle.

Thorp's experiments are reported as they run, in Quentin Luck's series on Demiton's blog: https://demiton.io/blog/series/quentin-luck. The first piece is the score the kernel is judged by; the next is two thousand books and a Mac mini.
